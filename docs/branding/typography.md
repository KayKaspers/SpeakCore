## Schriftfamilie

- Primär: **Inter** (oder vergleichbare moderne, gut lesbare Sans-Serif).
- Monospace (für Logs, Ports, IDs): system-monospace-Stack.

Token: `--sc-font-sans`, `--sc-font-mono`.

## Skala (vorläufig)

| Rolle | Token | Größe |
|-------|-------|-------|
| Display | `--sc-text-display` | 30px / 2.25rem |
| H1 | `--sc-text-h1` | 24px / 1.5rem |
| H2 | `--sc-text-h2` | 20px / 1.25rem |
| Body | `--sc-text-body` | 16px / 1rem |
| Small | `--sc-text-sm` | 14px / 0.875rem |
| Caption | `--sc-text-caption` | 12px / 0.75rem |

## Prinzipien

- Klare Hierarchie, gut lesbar auch in dichten Dashboards (Enterprise-Dark-Ästhetik).
- Monospace für technische Werte (Logs, Ports) zur besseren Scanbarkeit.
- Zeilenlängen und -höhen auf Lesbarkeit optimieren; keine zu engen Zeilenabstände.

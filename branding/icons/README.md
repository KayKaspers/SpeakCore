# SpeakCore Icons

| Datei | Verwendung |
|-------|------------|
| `favicon.svg` | Browser-Favicon (vereinfachte Mark, ohne Knoten, optimiert für kleine Größen) |
| `app-icon.svg` | App-/Launcher-Icon (gerundeter dunkler Hintergrund + Mark), 512×512 |

Beide nutzen die SpeakCore-Markenfarben (Primary→Accent). Für PNG-Export (z. B. `apple-touch-icon`)
kann das SVG bei Bedarf später gerastert werden – in 0.1 bleibt es bei SVG.

Status: **Platzhalter**, repository-tauglich. Siehe [../guidelines/logo-usage.md](../guidelines/logo-usage.md).

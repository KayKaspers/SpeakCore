# SpeakCore Logos

SVG-Vektoren (Platzhalter-Qualität, aber repository-tauglich). **Keine Binärdateien, keine
eingebetteten Fonts** – Schrift via System-Fallback (`Inter, …, sans-serif`).

## Designidee

Hexagon (Infrastruktur-/Schild-Anmutung) mit stilisiertem „S" und drei Netzwerk-Knoten.
Markenfarbverlauf Primary → Accent (`#2563EB` → `#06B6D4`). Enterprise-Dark, klare Linien.

## Dateien

| Datei | Verwendung |
|-------|------------|
| `speakcore-logo.svg` | Vollständiges Logo (Mark + Wortmarke), neutral/dunkel |
| `speakcore-logo-dark.svg` | Logo für **dunkle** Hintergründe (heller Text) |
| `speakcore-logo-light.svg` | Logo für **helle** Hintergründe (dunkler Text) |
| `speakcore-mark.svg` | Kompakte Mark (Badge auf Surface) |
| `speakcore-mark-dark.svg` | Mark transparent/hell für dunkle Flächen |
| `speakcore-mark-light.svg` | Mark für helle Flächen |

Wortmarke: zweifarbig „**Speak**" (Text) + „**Core**" (Accent).
